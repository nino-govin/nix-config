# CLAUDE.md

## System Overview

NixOS laptop (`nino-nixos`), flakes + home-manager. Hyprland (Wayland) with a Quickshell greeter (greetd). Intel iGPU primary + NVIDIA dGPU via PRIME offload.

## Build & Deploy

```bash
sudo nixos-rebuild switch --flake /etc/nixos#nixos
nix flake update
nix-collect-garbage -d
```

## Architecture

**Flake:** nixpkgs 26.05, hostname `nixos`, user `nino-nixos`

**System modules** (`modules/`):
- `boot.nix`: systemd-boot, 0 timeout, 3 gen limit
- `nvidia.nix`: PRIME offload (Intel `PCI:0:2:0`, NVIDIA `PCI:1:0:0`), proprietary drivers (`open = false`), finegrained power mgmt, nvidia modules removed from `modules-load.d` and loaded async by a udev rule (`modprobe nvidia_drm`) so they don't block `sysinit.target`
- `display.nix`: Hyprland + XDG portals
- `greeter.nix`: greetd runs a minimal Hyprland with `home/quickshell/greeter.qml` (state synced to `/var/lib/jaqc-greeter`); `tuigreet` specialisation as fallback
- `powersave.nix`: includes `nvme_core.io_timeout=2` (Intel VMD, locked on in BIOS, drops one NVMe interrupt at boot; default 30s timeout stalled initrd)
- `nix-ld.nix`, `ai.nix`, `gaming.nix`
- `packages/`: split into system/desktop/dev/media/apps

**Home modules** (`home/`):
- `hyprland.nix` + `hyprland.lua`: config uses **Lua** (`configType = "lua"`), monitor eDP-1 @ 2560x1600@240Hz scale 1.6, layouts fr,us, AZERTY bindings
- `quickshell.nix`: Quickshell desktop shell (Hyprland port of JAQC-shell), config symlinked from `/etc/nixos/home/quickshell/`, runs as systemd user service after `hyprland-session.target`. Runtime files (`settings.json`, generated theme files) are gitignored. Old shell in `home/quickshell-old/`
- `adaptive-refresh-rate.nix`: systemd user service/timer (30s after boot, every 10s), adjusts refresh rate by power state
- `scripts.nix`: steam-nvidia.desktop (PRIME offload), VSCode icon resize, `screenshot` (grim + notify)
- `default.nix`: Firefox (DPR 1.6), Papirus-Dark icons, GTK + qt5ct/qt6ct colors generated by Quickshell integrations, keychain `id_ed25519_github2`, hyprpolkitagent
- Other: wofi, kitty, zsh, starship, dunst, git, hypridle, hyprlock, media

## Key Details

- `nvidia-offload <cmd>` available system-wide
- Startup: `cliphist`; wallpaper drawn by Quickshell from `~/Pictures/Wallpapers`
- Quickshell IPC drives media keys, lock, power menu, wallpaper picker, clipboard (`qs ipc call <target> <fn>`)
- Hyprland `hyprctl dispatch` takes Lua (`hl.dsp.*`), not legacy dispatcher syntax
- Unfree allowed, flakes + nix-command enabled, auto-optimise-store, weekly GC (>7d)
- State version: 25.11
