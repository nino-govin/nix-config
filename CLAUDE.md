# CLAUDE.md

## System Overview

NixOS laptop, flakes + home-manager. Hyprland (Wayland, Lua config) with a Quickshell shell and greeter (greetd). Intel iGPU primary + NVIDIA dGPU via PRIME offload. Full documentation in `README.md` (structure, "where to put things", NVIDIA/boot/power internals).

## Build & Deploy

```bash
nixos-rebuild build --flake /etc/nixos#nixos        # verify without sudo
sudo nixos-rebuild switch --flake /etc/nixos#nixos  # user runs this in kitty (sudo needs a tty)
nix fmt                                             # nixfmt-tree
nix store diff-closures /run/current-system ./result
```

New files must be `git add`ed before building (flakes only see tracked files).

## Architecture

**Flake:** nixpkgs 26.05, one host `nixos` (`hosts/nixos/`), user `nino-nixos`.

**Shared values:** `hosts/nixos/vars.nix` is passed as the `host` argument to NixOS and home-manager modules (`host.user`, `host.monitor`, `host.monitorLua rate`). Never hardcode the user name or monitor spec.

**System modules** (`modules/`, each folder has a `default.nix` import list):

- `core/`: boot (systemd-boot, timeout 0, 3 generations), `nix.nix` (unfree, flakes, GC, `claude-code` overlay from nixpkgs-unstable), locale, networking (Tailscale), users, security
- `hardware/`: `nvidia.nix` (PRIME offload, async module loading via udev, `fbdev=0`, defines `nvidiaOffloadEnv` module arg), `power.nix` (auto-cpufreq, `power-profile-apply` root script + NOPASSWD sudo rule, NVMe/VMD kernel params), audio, bluetooth
- `desktop/`: display (Hyprland, portals, session vars), greeter (Quickshell greeter, `tuigreet` specialisation fallback), fonts, desktop CLI tools called by binds/Quickshell
- `services/`: ai (ollama-cuda), gaming (Steam, osu! wrapped with `nvidiaOffloadEnv`), virtualisation (docker), nix-ld
- `packages.nix`: base CLI tools

**Home modules** (`home/`):

- `desktop/`: `hyprland.nix` generates monitor/cursor Lua then `require("config")` → `hyprland.lua`; `quickshell.nix` (user service, out-of-store symlink to `home/quickshell/`); hypridle; `power.nix` (`set-power-profile` → `~/.local/bin`, `adaptive-refresh-rate` timer, only acts in `balanced`); `scripts.nix` (`screenshot`)
- `shell/`: zsh (aliases `rebuild`, `update`, `cleanup`, `comfy`…), starship, kitty (Nord fallback + Quickshell colors include), direnv, git, ssh/keychain
- `theming.nix`: GTK, qtct (colors generated by Quickshell), Bibata cursor
- `apps.nix`, `dev.nix`: user packages (gcc has `hiPrio` over clang)
- `quickshell/`: QML sources (JAQC-shell port). Runtime files are gitignored

## Key Details

- `nvidia-offload <cmd>` available system-wide
- Quickshell IPC: `qs ipc call <target> <fn>` (launcher, clipboard, wallpaper, powermenu, lockscreen, audio, brightness)
- Hyprland `hyprctl dispatch`/`eval` take Lua (`hl.dsp.*`, `hl.config`), not legacy syntax
- Hyprland window rule matches are RE2 regex: escape dots as `\\.` in Lua strings, never Lua patterns (`%.`)
- State version: 25.11
